- (decision) Paradigm: ports-and-adapters (hexagonal) wrapped around an append-only observation log, with a strictly one-way capture pipeline. Chosen because the spec's two hardest guarantees are both structural, not behavioural: raw audio must not escape the home, and v1 must make no judgement. Both are enforceable as dependency directions; neither survives as a coding convention.
- (decision) AD-1 append-only observation log is the single source of truth for everything derived from the senior. Prevents retroactive rewriting that would destroy the evidentiary value v2 depends on.
- (decision) AD-2 audio trust boundary: raw audio never leaves the device context. Only extracted observations cross the network. Prevents raw audio reaching application stores, logs, or persisted model prompts.
- (decision) AD-3 the no-judgement rule is enforced by dependency direction, not discipline: no v1 component may read the log in a way that compares, aggregates, orders, or thresholds across entries. Render surfaces get a per-senior windowed read model with no comparison primitives. Prevents a well-meaning dashboard feature shipping judgement into an unregulated product.
- (decision) AD-4 consent is a write-path precondition, not a UI check. The log rejects observations for any senior without an active three-artefact enrolment. Prevents partial enrolments collecting data and per-surface reimplementation of the rule.
- (decision) AD-5 addressed-turn determination runs on-device before any network egress. Prevents cloud-side filtering, which would mean unaddressed audio had already left the home.
- (decision) AD-6 device liveness is a separate first-class series. Unreachable time is recorded as a gap, never as reduced interaction. Prevents phantom decline from a dead unit.
- (decision) AD-7 one owner per entity: the Enrolment context owns the senior record; family and care worker exist only as scoped grants against it. Prevents two writers of the same person.
- (decision) AD-8 all human-facing text passes through a single Composer applying communication-rules.md. No surface composes its own copy. Prevents forbidden vocabulary appearing on one surface only.
- (decision) AD-9 instrument scheduling and refractory-window eligibility are computed in exactly one place. Prevents two schedulers double-administering an item and destroying the rotation guarantee.
- (decision) AD-10 every observation carries provenance: the interaction it came from, its date, and the item-bank variant where applicable. Prevents unciteable entries, which are worthless to v2.
- (decision) AD-11 timestamps stored UTC ISO-8601; all windowing computed in Asia/Singapore. Prevents day-boundary drift corrupting a day-resolution series.
- (decision) AD-12 the LLM is an adapter behind a port. Consent gating, item eligibility, redaction, and the communication rules are deterministic code, never prompt instructions. Prevents nondeterministic policy enforcement.
- (decision) AD-13 erasure on an append-only log is done by crypto-shredding a per-senior key plus tombstone events, never by deleting entries. Resolves the direct conflict between AD-1 and the withdrawal/death obligations in consent-and-data-governance.md.
